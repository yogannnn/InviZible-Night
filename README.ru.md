## О проекте

InviZible Night появился потому, что сопровождающий форк хочет развивать
приложение с несколько иными настройками по умолчанию и принципами
выбора источников, продолжая работу на основе InviZible Pro.

Описанные ниже отличия --- это **технические решения и особенности
направления развития проекта**. Их не следует воспринимать как критику
оригинального автора или утверждение, что оригинальный проект
небезопасен либо поддерживается ненадлежащим образом. Автор
оригинального приложения вправе придерживаться собственных принципов и
принимать иные решения. Этот форк не претендует на то, чтобы
представлять его взгляды.

### Текущие отличия

-   **Отдельный идентификатор приложения:**
    `com.yogannnn.invizible.night`. InviZible Night можно устанавливать
    одновременно с оригинальным InviZible Pro при соблюдении стандартных
    ограничений Android, связанных с пакетами и подписями приложений.
-   **Отдельное название:** `InviZible Night`.
-   **Мосты Tor:** в качестве источника по умолчанию используется
    [сервис распространения мостов Tor
    Project](https://bridges.torproject.org/). При этом в форке нет
    принципиального ограничения, запрещающего использовать общедоступные
    источники мостов, размещённые на GitHub. Любой дополнительный
    источник должен быть отдельно поддержан или настроен в
    соответствующей сборке. Это не означает, что любой список мостов на
    GitHub автоматически считается надёжным или включён в приложение.
-   **Подписки I2P:** в этой версии вместо `notbob.i2p` используется
    `inr.i2p`.

### О выборе источников

Выбор источников мостов и подписок --- одна из областей, в которых
предпочтения сопровождающего форк отличаются от предпочтений
оригинального проекта.

В частности, в отношении подписок I2P у сопровождающего есть вопросы к
прозрачности правил отбора источников и фильтрации содержимого. Поэтому
в форке предпочтение отдано другому источнику. Это описание личной
позиции и мотивов сопровождающего, **а не утверждение о том, что
недобросовестные действия операторов `notbob.i2p` доказаны**.

Аналогично, возможность использовать списки мостов Tor, размещённые на
GitHub, не означает, что любой такой источник надёжен. Источники следует
оценивать с учётом их происхождения, сопровождения, целостности и
пригодности. Пользователям стоит самостоятельно решать, каким источникам
они доверяют.

Эти решения не преподносятся как единственно правильный подход. Это
просто направление, выбранное для данного независимого форка.

## Установка

1.  Откройте вкладку
    [Actions](https://github.com/yogannnn/InviZible-Night/actions) этого
    репозитория.
2.  Выберите успешный запуск workflow для ветки `night`.
3.  Скачайте артефакт `InviZible-Night-APK`.
4.  Установите APK на Android-устройство.

Благодаря отдельному идентификатору приложения форк рассчитан на
совместную установку с оригинальным InviZible Pro. При этом Android
может потребовать разрешить установку приложений из используемого
источника. Сборки, распространяемые в этом репозитории, являются
неофициальными и сопровождаются независимо от релизов оригинального
проекта.

## Сборка из исходного кода

Клонируйте репозиторий вместе с подмодулями (это необходимо для работы
проекта, в том числе для `android-filepicker`):

``` bash
git clone --recursive https://github.com/yogannnn/InviZible-Night.git
cd InviZible-Night
git checkout night
```

Откройте проект в Android Studio. Текущая конфигурация сборки
использует:

-   JDK 17
-   Android SDK 37
-   NDK 23.1.7779620

Для сборки release APK выполните:

``` bash
./gradlew assembleFdroidUniversalRelease
```

Подписание настроено через переменные окружения `KEYSTORE_PASSWORD`,
`KEY_ALIAS` и `KEY_PASSWORD`, а также файл `release-key.jks`. Для
локальной сборки в корне проекта можно создать файл
`keystore.properties`.

Требования к сборке и настройки подписи могут меняться по мере развития
форка. Точные параметры для конкретной версии проверяйте в
workflow-файлах и конфигурации Gradle.
